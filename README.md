# 🎵 Spotify Analyzer

Analyze Spotify music datasets and personal listening
history using Python, Pandas, NumPy and data visualization.

## Features

- Dataset cleaning and validation
- Artist analysis
- Genre analysis
- Audio feature analysis
- Correlation analysis
- Listening statistics
- Music profile
- Diversity analysis
- Dataset comparison
- Interactive Streamlit dashboard
- CLI interface
- CSV/JSON support

## Tech Stack

Python
Pandas
NumPy
Matplotlib
Seaborn
Streamlit
Pytest

### Note:
Beginner project for my data science learning journey showcasing learned skills for the tech stack mentioned above and other basic skills.
